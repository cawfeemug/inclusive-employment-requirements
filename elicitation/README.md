# Elicitation

> **All interview and survey data in this project is simulated.** It was created for coursework to practise elicitation and requirement derivation. It does not come from real participants.

## Method

| Technique | Purpose |
|---|---|
| Semi-structured interviews (3) | Qualitative insight into accessibility barriers, privacy concerns, accommodation needs and employer requirements |
| Survey (20 questions, 15 responses) | Structured view of how stakeholders prioritise accessibility, privacy, matching, interview and safety features |

The two sources were cross-referenced. Findings supported by both an interview and the survey were given higher confidence when deriving requirements.

## Coverage

| Stakeholder group | Interview | Survey |
|---|:-:|:-:|
| Physical disability | ✓ | ✓ |
| Visual / hearing disability | | ✓ |
| Cognitive / learning disability | ✓ | ✓ |
| Psychosocial / mental health | | ✓ |
| Employer / HR | ✓ | ✓ |
| Job coach / support worker | | ✓ |

Three groups were covered by the survey only. Requirements that rely on them are flagged in the [traceability matrix](../docs/traceability-matrix.md#coverage-check).

## Key findings

**Interviews**
- **INT-01 (physical disability):** Workplace-accessibility information should be available before applying, and disclosure should stay under the user's control.
- **INT-02 (cognitive disability):** Plain language, applications broken into smaller steps, saved drafts and notification control.
- **INT-03 (employer):** Applicants should be assessed on skills before any disability information is seen, and employer verification builds trust.

**Survey** (evidence strength in brackets)
- **SF-01 (High):** Accessibility information is highly valued.
- **SF-02 (High):** Users need accessible navigation, assistive-technology support and alternative formats.
- **SF-03 (High):** Users want to save and resume applications.
- **SF-04 (High):** Disability disclosure should be optional.
- **SF-05 (High):** Skills should be prioritised over disability.
- **SF-06 (Medium–High):** Users want transparency in job recommendations.
- **SF-07 (High):** Flexible interview methods are desirable.
- **SF-08 (High):** Supporter access should require consent.
- **SF-09 (High):** Discrimination, scams and misleading information should be reportable.
- **SF-10 (High):** Employer verification is important.
